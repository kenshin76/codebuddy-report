# CodeBuddy 구독 요금제 번역 및 비교

작성일: 2026-11-25 (Asia/Seoul)

이 문서는 사용자가 제공한 요금제 이미지 4장의 표시 내용을 번역하고 비교한 자료다. 현재 웹사이트의 실시간 요금이나 결제 조건을 조회한 자료는 아니다. 가격은 모두 미국 달러(USD)이며 세금·환율·환불·자동 갱신 조건은 이미지에 나오지 않는다.

## 1. 자료와 화면 구성

| 자료 | 화면 | 확인한 내용 |
|---|---|---|
| 이미지 1 | Personal → Monthly | 개인 Free 및 Pro 월 결제 가격과 기능 |
| 이미지 2 | Personal → Yearly · 20% off | 개인 Free 및 Pro 연 결제 가격과 기능 |
| 이미지 3 | Business → Monthly | Team 월 결제 가격, 크레딧 프로모션, 기업 기능 |
| 이미지 4 | Business → Yearly | Team 연 결제 가격, 크레딧 프로모션, 기업 기능 |

Personal/Business는 고객 구분이고 Monthly/Yearly는 결제 주기다. 실제 요금제 이름은 Free, Pro, Team이다. 따라서 월 결제 Pro와 연 결제 Pro는 기능이 다른 별도 등급이 아니다. Team도 두 결제 주기의 표시 기능이 동일하다.

## 2. 가격 비교

아래 연간 금액은 화면 가격을 유지한다고 가정한 단순 계산이다. 월 결제를 12회 하는 금액과 연 결제 표시 가격을 구분했다.

| 항목 | Free | Pro 월 결제 | Pro 연 결제 | Team 월 결제 | Team 연 결제 |
|---|---|---|---|---|---|
| 고객 구분 | 개인 | 개인 | 개인 | 기업·팀 | 기업·팀 |
| 화면 가격 | $0/월 | $10/월 | 월 환산 $8, 연 단위 청구 | $40/좌석/월 | $480/좌석/년 |
| 월 환산 금액 | $0 | $10 | $8 | $40/좌석 | $40/좌석 |
| 12개월 금액 | $0 | $120 | **$96** | $480/좌석 | **$480/좌석** |
| 연 결제 절감액 | 해당 없음 | 비교 기준 | **연 $24, 20%** | 비교 기준 | **$0, 0%** |
| 월 결제 대비 연 결제 전용 기능 | 해당 없음 | 해당 없음 | 이미지상 없음 | 해당 없음 | 이미지상 없음 |

가격 해석:

- Pro 연 결제의 `$8/mo (Billed yearly)`는 월 $8씩 청구한다는 뜻이 아니라 **연 결제 금액 $96의 월 환산액**이다.
- 개인 화면의 `Yearly · 20% off`는 Pro 월 $10과 연 결제 월 환산 $8을 비교하면 일치한다.
- Pro 가격 옆에는 취소선으로 `20/mo`가 표시되어 있다. 원래 가격 또는 비교 가격으로 제시된 숫자지만, 적용 기간·갱신 가격이 설명되어 있지 않으므로 향후 $20이 청구된다고 단정하지 않는다. 연 결제의 20% 절감 계산도 이 취소선 가격이 아닌 현재 월 결제 $10을 기준으로 한다.
- Team은 월 $40 × 12 = 연 $480이므로 **첨부 화면에는 연 결제 할인 이점이 없다.** 개인 Pro의 20% 할인을 Team에 적용하지 않는다.
- Team의 seat는 사용자 이용권을 세는 단위인 **좌석**이다. 최소 구매 좌석 수는 이미지에서 확인되지 않는다.

## 3. 크레딧과 개발 기능 비교

`미표기`는 해당 이미지에서 확인할 수 없다는 뜻이다. 제공되지 않는다고 확정한 것이 아니다.

| 비교 항목 | Free | Pro | Team | 근거·해석 |
|---|---|---|---|---|
| 기본 크레딧 | 월 100 | 월 1,000 | 좌석당 월 1,000 | 이미지 1~4 |
| 보너스 크레딧 | 별도 보너스 미표기 | 월 1,000 | 좌석당 월 1,000 | Team은 한정 프로모션과 함께 표시 |
| 기본 + 표시 보너스 합계 | 월 100 | **월 2,000** | **좌석당 월 2,000** | 일일 활동 보상 제외 |
| 일일 활동 보상 | 활동일당 30 | 활동일당 50 | 미표기 | 접속만으로 인정되는지 등 세부 조건 미표기 |
| 모델 이용 | 자동 모델 라우팅 | **전체 모델 접근** | 미표기 | Team의 기업 모델 구성 기능은 별도 표시됨 |
| 코드 자동 완성 | 5,000회 | **무제한** | 미표기 | Free의 집계 주기는 이미지에 명시되지 않음 |
| 자동화 작업 | 3개 | **15개** | 미표기 | 실행 횟수·동시 실행 수·등록 한도 중 무엇인지 미표기 |
| 전문가·스킬·커넥터 | 제공 | 제공 | 같은 일반 항목은 미표기 | Team은 기업용 전문가·스킬을 별도 명시 |
| 여러 파일을 함께 이해 | 제공 | 제공 | 미표기 | Cross-file understanding |
| 주석을 바탕으로 코드 생성 | 제공 | 제공 | 미표기 | Generate code from comments |

크레딧은 제품 내 사용량 단위이며 토큰 수와 같은 단위가 아니다. `전체 모델 접근`은 CodeBuddy에서 해당 계정에 제공하는 모델을 이용할 수 있다는 표시이지, 전 세계 모든 LLM이나 무제한 AI 요청을 뜻하지 않는다. 개별 지원 모델명은 네 이미지에 없다.

또한 Pro의 **무제한은 코드 자동 완성 항목**에 붙어 있다. 대화·에이전트 작업·프로젝트 개발 전체가 크레딧 제한 없이 무제한이라는 의미로 확대하지 않는다.

### 3.1 일일 활동 보상을 포함한 단순 계산

모든 활동일이 보상 조건을 만족하고, 해당 기간의 모든 표시 보상이 적용된다는 가정에서 활동일 수를 `D`라고 두면 다음과 같다. 이는 기간 중 지급될 수 있는 크레딧의 산술 예시이며 실제 잔액·보장 지급량이 아니다. 소멸·사용·지급 시점은 반영하지 않았다.

| 항목 | Free | Pro |
|---|---|---|
| 계산식 | `100 + 30 × D` | `1,000 + 1,000 + 50 × D` |
| 30일 모두 보상 대상인 경우 | 1,000크레딧 | 3,500크레딧 |

Team의 일일 활동 보상은 미표기이므로 Pro의 일일 50크레딧을 Team에 추가하지 않는다. 연 결제 화면도 크레딧을 **월 단위**로 표시하므로 연간 분량이 한 번에 지급된다고 해석하지 않는다.

## 4. Pro에서 추가되거나 확대되는 혜택

| Free 대비 변화 | Free | Pro | 의미 |
|---|---|---|---|
| 월 정기 크레딧 증가 | 100 | 기본 1,000 + 보너스 1,000 | 표시 보너스 포함 20배. 보너스의 영구 지속 여부는 미확인 |
| 일일 활동 보상 증가 | 30 | 50 | 보상 대상 활동일당 20 증가 |
| 전체 모델 접근 명시 | 자동 라우팅 | 전체 모델 접근 | 특정 모델을 정해 비교 개발을 할 때 확인할 항목 |
| 코드 자동 완성 확대 | 5,000회 | 무제한 | 자동 완성 사용량 제한 완화 |
| 자동화 작업 확대 | 3개 | 15개 | 표시 작업 수 5배 |

전문가·스킬·커넥터, 여러 파일 이해, 주석 기반 코드 생성은 **Free에도 표시**되어 있으므로 Pro 전용 기능으로 분류하지 않는다. Pro 월 결제보다 연 결제에 추가되는 기능은 이미지상 없으며 차이는 결제 주기와 가격이다.

## 7. 비용과 제공량의 관계

| 비교 | 계산 | 읽는 방법 |
|---|---|---|
| Pro 월 결제 대비 연 결제 | `$120 - $96 = $24`, `$24 ÷ $120 = 20%` | 연 결제 시 12개월 기준 $24 절감 |
| Team 월 결제 대비 연 결제 | `$40 × 12 = $480` | 화면 가격상 연 결제 할인 없음 |
| Team과 Pro 월 결제 | `$40 ÷ $10 = 4` | Team은 좌석당 4배 가격 |
| Team과 Pro 연 결제 월 환산 | `$40 ÷ $8 = 5` | Team은 좌석당 5배 가격 |
| Pro와 Team의 표시 월 크레딧 | 각각 기본 1,000 + 보너스 1,000 | Team 한 좌석이 Pro보다 더 많은 정기 크레딧을 제공한다고 볼 수 없음 |

예를 들어 Team 5좌석은 월 결제 시 월 $200, 연 결제 시 연 $2,400이다. 프로모션 표시대로라면 좌석별 지급량의 합은 월 기본 5,000 + 보너스 5,000 = 10,000크레딧이다. 이 합계만으로 팀 전체가 크레딧을 자유롭게 공유·이전할 수 있다고 확정하지 않는다.

이 표는 요금 비교용 산술 계산이다. 크레딧당 토큰 환산율과 모델별 차감률이 없으므로 **입력·출력·캐시 토큰의 USD/1M 단가나 프로젝트 한 건의 실제 비용은 계산할 수 없다.** 월 구독료를 모델 API의 토큰 단가로 취급하지 않는다.

## 8. 이미지에서 확인되지 않은 조건

| 항목 | 현재 자료의 한계 |
|---|---|
| 세금·원화 청구 금액 | USD 표시만 있으며 세금 포함 여부와 환율 미표기 |
| 할인·보너스 지속 기간 | Pro 취소선 가격, 보너스 크레딧, Team 프로모션의 종료·갱신 조건 미표기 |
| 크레딧 정책 | 유효기간·이월·차감 순서·추가 충전 가격·모델별 소모율 미표기 |
| 일일 보상 인정 기준 | 지급 대상 행동·시각·상한·프로모션 기간 미표기 |
| 코드 자동 완성·자동화 작업 | Free 자동 완성의 집계 주기와 자동화 작업 수의 정확한 의미 미표기 |
| Team 일반 개발 기능 | 전체 모델 접근·자동 완성·자동화 작업의 Team 한도는 카드에 미표기 |

## 10. Personal Pro와 Business Team Monthly 비교 — 프로모션 제외

추가일: 2026-11-25

동일한 결제 주기로 비교하기 위해 **Personal Pro 월 결제와 Business Team 월 결제의 1좌석**을 비교한다. 크레딧 비교에서는 **기간 한정으로 명시된 Team의 보너스 1,000크레딧과 크레딧 두 배 행사만 제외**한다. Pro의 월 보너스 1,000크레딧과 일일 활동 보상 50크레딧은 이미지에 기간 한정 표시가 없으므로 포함한다. 가격은 별도로 연 결제 할인과 화면 할인 가격을 제외한 참고 기준을 아래에 명시한다. 앞 절의 이미지 원문 번역과 프로모션 포함 표는 원자료 기록으로 유지한다.

Pro의 `1,000 bonus credits/month`는 매월 지급하는 혜택으로 표시되어 있다. 다만 **기간 한정 표시가 없다는 사실과 향후 영구 유지가 보장된다는 주장은 다르다.** 일일 50크레딧도 활동 보상 조건을 만족한 날에 적용하며, 활동하지 않은 날까지 자동 지급된다고 가정하지 않는다. Team에는 `Limited Time · Double Credits`와 `LIMITED`가 명시되어 있어 보너스를 한정 행사로 구분할 근거가 있다.

### 10.1 가격과 기본 제공량

Pro 화면에는 월 $10과 취소선 월 $20이 함께 표시되어 있다. **할인을 제외한 비교에는 취소선 $20을 참고 가격으로 사용하지만, 이미지에는 이를 정상가·할인 종료 후 청구액으로 확정하는 설명이 없다.** 따라서 아래 $20 및 그에 따른 차액·배수는 비교 가정이며, 프로모션 없는 실제 Pro 청구 가격은 미확인이다. Team 월 $40에는 별도 취소선 할인 가격이 없다.

| 비교 항목 | Personal Pro — 월 결제 | Business Team — 월 결제, 1좌석 |
|---|---|---|
| 이용 형태 | 개인용 유료 구독 | 기업·팀용 좌석 구독 |
| 할인 제외 가격의 확인 상태 | 확정 불가. 화면 취소선 가격 **$20/월**을 참고 기준으로 사용 | 화면 표시 **$40/좌석/월**. 별도 가격 할인 미표기 |
| 위 참고 기준의 12개월 단순 합계 | $240 | $480/좌석 |
| 기본 크레딧 | **월 1,000** | **좌석당 월 1,000** |
| 비교에 포함하는 월 보너스 | **월 1,000** — 이미지에 기간 한정 표시 없음 | **0** — 한정 행사 보너스 1,000을 이번 계산에서 제외 |
| 비교에 포함하는 정기 월 크레딧 | **2,000** — 기본 1,000 + 보너스 1,000 | **1,000/좌석** — 기본 지급량만 포함 |
| 일일 활동 보상 | **보상 대상 활동일당 50** | 미표기. 0 지급으로 확정하지 않음 |
| 월 활동일 수 D를 반영한 계산 | **`2,000 + 50 × D`** | **`1,000/좌석`** — 미표기 보상은 산입하지 않음 |
| 30일 모두 활동 보상 대상인 예시 | **3,500** | **1,000/좌석** |
| 이번 비교에서 제외한 혜택 | 월 보너스·일일 활동 보상은 유지. 가격 비교에서 화면 할인 가격 및 연 결제 할인 제외 | 좌석당 월 보너스 1,000 및 크레딧 두 배 행사 |

참고 가격 $20을 가정하면 Team은 Pro보다 월 $20, 12개월 합계 $240 비싸며 가격은 2배다. **이 절에는 할인 표시 가격 $10을 적용한 4배 비교를 사용하지 않는다.** 기본 크레딧만 보면 동일하지만, Pro의 월 보너스를 유지하면 비교 대상 정기 월 크레딧은 Pro 2,000 대 Team 1,000으로 **Pro가 2배**다. 30일 모두 활동 보상 대상이면 산술 예시는 3,500 대 1,000으로 **Pro가 3.5배**다. 이 예시는 지급량 합계이며 사용·소멸을 반영한 실제 잔액이 아니다. 실제 프로모션 종료 후 청구액이나 혜택의 장기 유지를 보장하는 계산도 아니다.

### 10.3 비용 차이에 대응하는 기능

기본 크레딧은 양쪽 모두 월 1,000이지만, **한정 표시가 없는 Pro의 월 보너스를 포함하고 Team의 한정 보너스만 제외하면 Pro는 월 2,000 + 활동일당 50, Team은 좌석당 월 1,000**이다. 따라서 이 기준에서는 개인에게 제공되는 크레딧 양이 Pro 쪽에 더 많다. Team에서 추가로 명시한 가치는 SSO, 조직 관리, 구독 통합 관리, 구성원별 사용량 제어, 기업용 스킬·전문가·모델 구성, 보안·감사 및 API 연동이다.

개인 단위 개발·모델 비교에서 확인할 항목은 Pro의 모델 접근 범위와 사용량이고, 여러 구성원을 운영할 때 확인할 항목은 Team의 조직 관리 기능이다. 첨부 이미지에는 Team의 더 높은 LLM 성능·응답 속도·컨텍스트 또는 추가 기본 크레딧을 뒷받침하는 표시가 없다. 토큰당 비용도 이 자료만으로는 계산할 수 없다.

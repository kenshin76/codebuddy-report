## 범위와 제외 항목

- DeepSeek: 현재 토큰 그래프와 대응하는 프록시 개발·검토 창을 적용했습니다. 별도 UI 두 화면 10.40크레딧과 더하지 않습니다. 과제 전용 귀속과 UI 연결은 미확인입니다.
- HY4: 개발 W1 324.69 + 검토·재검증 W3 400.87 = 725.56입니다. W2 단계 미분류 66.52크레딧을 넣으면 문서 제외 창은 792.08이지만, 그래프의 개발+검토와 범위가 달라 여기에는 더하지 않습니다. W4 문서 작업 28.62도 제외합니다. 미수집 7건을 0으로 채우지 않습니다.
- Kimi: 주 UI 709.34+569.08=1,278.42입니다. 별도 agent 표시 21,277크레딧은 UI와 포함·중복 관계가 미확인이라 추가하지 않습니다.

- Balanced: 11월25일 새 실행의 개발562.32+검토255.91=818.23입니다. 이전 실행의 UI891.21 및 시간 분리 문서11.24크레딧을 더하지 않습니다. 원본 화면·전체 요청 포괄 미확인인 전사 소계입니다.

## 계산식

`비용(USD) = (개발 크레딧 + 검토 크레딧) × 40 ÷ 1,000`

입력·출력·캐시 토큰에 1M 단가를 다시 곱하거나 리뷰 시험 단가를 추가 적용하지 않습니다. 기록상 관측 범위와 실제 청구액을 구분합니다.
